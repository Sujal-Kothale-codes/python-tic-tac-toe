#  Python Tic-Tac-Toe Game

A simple two-player Tic-Tac-Toe game developed using Python and Tkinter. The game provides a graphical interface where two players take turns placing X and O on a 3×3 board.

##  Features

-  Graphical user interface using Tkinter.
-  Two-player gameplay.
- Automatic player turn switching.
-  Winner detection.
-  Highlights the winning combination.
-  Detects when the game ends in a draw.
-  Displays popup messages for wins and draws.

##  Technologies Used

- Language: Python
- GUI Library:Tkinter
- Editor: Visual Studio Code

##  Requirements

- Python 3.0
- Tkinter (usually included with standard Python installations)

##  How to Run

Step 1: Clone the repository.

bash
git clone https://github.com/sujal-kothale-codes/python-tic-tac-toe.git


Step 2:Open the project folder.

bash
cd python-tic-tac-toe


Step 3: Run the Python file.

bash
python python.py


A game window will open. Click any empty square to make your move.

##  How to Play

1. Player X starts the game.
2. Player O takes the next turn.
3. Players alternate turns by clicking empty squares.
4. The first player to complete a horizontal, vertical, or diagonal line wins.
5. If all nine squares are filled without a winner, the game ends in a draw.
